# txtFormat 1.0.4

换了一套新的应用图标，其余功能与 1.0.3 相同。

## Highlights

- **程序图标重做**：由旧版的「白纸页 + 三行文字 + 对勾」换成「书脊竖条 + 四行横条」，
  底板仍是棕色圆角方块，应用在标题栏、任务栏、开始菜单与安装向导上。
- 界面强调色（主按钮、勾选、链接、选中态）本来就由程序图标的主色算出来，
  图标一换，整套界面配色跟着换，不用另外调。
- **安装向导侧栏图标不再发虚**：按 ico 里真实的 256×256 帧取图，细线条 logo 高分屏下也清晰。
- 功能与 [1.0.3](https://github.com/RexLee0929/txtFormat/releases/tag/v1.0.3) 一致，
  逐条变更见 [CHANGELOG](https://github.com/RexLee0929/txtFormat/blob/main/CHANGELOG.md)，
  功能说明见 [README](https://github.com/RexLee0929/txtFormat#readme)。

## 下载

- 下载 `txtFormat-1.0.4-setup.exe`，双击安装（简体中文向导，8 页）。
- 默认「仅为我安装」，装在当前用户目录，不需要管理员权限；也可以选「为所有用户安装」。
- 从 1.0.3 升级：直接装，配置默认保留。

## 系统要求

64 位 Windows 10 1903 及以上，或 Windows 11；约 65 MB 可用磁盘空间。
安装包已内置 Python 运行库与 Qt，不需要另外安装 Python；安装向导基于 .NET Framework 4.8，
Win10 1903 起和 Win11 都自带。

## 已知限制

- 这些历史格式没做：UMD（读与写）、TXT → JAR、TXT → PDF、PDF → TXT、EXE → HTM、HLP → RTF。
  点对应转换时会给一句明确提示，不会静默失败。
- MOBI / AZW 只支持非 HUFF 压缩的版本；CHM 只能转成 HTML，不直接出 TXT。
- 「的得地」检查用规则组实现，在搜索等级 1 时与原程序口径接近，但不会完全一致。
- 内置错别字表约 365 条高频词与异形词（原程序是约 18 万条自动生成的定长表，误报很多），
  可以自己往 `typos.txt` 里加。
- 阅读模式是只读的：隐藏行号、去掉当前行高亮、正文收进居中的窄栏，要改就切回整理模式。
- 只支持 Windows：标题栏配色、简繁转换都调用系统 API。
- 打开几十 MB 的单个文件会明显变慢，此时用「按大小分割」先切开更省事。
