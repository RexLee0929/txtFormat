# txtFormat 1.0.2

首个公开发布版本（1.0.1 为内部首次构建、未对外发布）：以原 txtFormat 文本校对 V2.10 为参照重写，
界面按 Windows 11 Fluent 重做，原有的处理项逐条对齐，全部功能在本机完成，不联网、不上传任何内容。

## Highlights

- **格式整理一键完成 11 步**：行尾清理、标点与英文数字全半角、硬回车合并、Unicode 码还原、
  广告行剔除、行首缩进与段落隔行、屏蔽码与拼音还原、标点组合规范；有选区时只整理选区。
- **正则查找替换可批处理**：82 条内置表达式加 `custreg.txt` 自定义条目，替换可一次性写回文件表里的所有文件，
  保留各自的编码与行尾。
- **章节整理**：10 种章节名预设、标题规范化、重排编号、删除章节名或整章、导出 `ChapterList.txt`，
  以及按章节或按大小分割、多文件合并。
- **安装与卸载都认「已有配置」**：安装向导会说明这次是更新、重装还是降级，配置默认保留；
  卸载默认留下 `config.json` 与 `custreg.txt`，并在完成页写明清了什么、留了什么。
- 格式转换支持 HTML / EPUB / DOCX / PDB / PRC / MOBI / AZW / JAR / RTF → TXT 与 CHM → HTML。
  完整清单见 [README](https://github.com/RexLee0929/txtFormat#readme)，逐条变更见 [CHANGELOG](https://github.com/RexLee0929/txtFormat/blob/main/CHANGELOG.md)。

## 下载

- 下载 `txtFormat-1.0.2-setup.exe`，双击安装（简体中文向导，8 页）。
- 默认「仅为我安装」，装在当前用户目录，不需要管理员权限；也可以选「为所有用户安装」。
- 装完可以从开始菜单、桌面快捷方式启动，或在 `Win+R` 里输入 `txtFormat`。

## 系统要求

64 位 Windows 10 1903 及以上，或 Windows 11；约 65 MB 可用磁盘空间。
安装包已内置 Python 运行库与 Qt，不需要另外安装 Python；安装向导基于 .NET Framework 4.8，
Win10 1903 起和 Win11 都自带。

## 已知限制

- 这些历史格式没做：UMD（读与写）、TXT → JAR、TXT → PDF、PDF → TXT、EXE → HTM、HLP → RTF。
  点对应转换时会给一句明确提示，不会静默失败。
- MOBI / AZW 只支持非 HUFF 压缩的版本；CHM 只能转成 HTML，不直接出 TXT。
- 「的得地」检查用规则组实现，在搜索等级 1 时与原程序口径接近，但不会完全一致。
- 内置错别字表约 365 条高频词与异形词（原程序是约 18 万条自动生成的定长表，误报很多），
  可以自己往 `typos.txt` 里加。
- 阅读模式是只读的：隐藏行号、去掉当前行高亮、正文收进居中的窄栏，要改就切回整理模式。
- 只支持 Windows：标题栏配色、简繁转换都调用系统 API。
- 打开几十 MB 的单个文件会明显变慢，此时用「按大小分割」先切开更省事。
