# txtFormat 1.0.5

改进字体选择、界面细节与错误提示。

## Highlights

- 字体选择器支持搜索、字体名称预览、字重、斜体和行距设置。
- 字体恢复默认值与程序实际默认设置一致。
- 未捕获异常时增加状态栏提示，并改进错误框与打开日志的入口。
- 不同程序目录使用各自的单实例标识。

## 下载

- 下载 `txtFormat-1.0.5-setup.exe`，双击安装；升级时默认保留配置。
- 完整变更见 [CHANGELOG](https://github.com/RexLee0929/txtFormat/blob/main/CHANGELOG.md)，使用说明见 [README](https://github.com/RexLee0929/txtFormat#readme)。

## 系统要求

64 位 Windows 10 1903 及以上，或 Windows 11；约 65 MB 可用磁盘空间。安装包内含 Python 运行库与 Qt；安装向导基于 .NET Framework 4.8，Win10 1903 起和 Win11 都自带。

## 已知限制

- 这些历史格式没做：UMD（读与写）、TXT → JAR、TXT → PDF、PDF → TXT、EXE → HTM、HLP → RTF。
  点对应转换时会给一句明确提示，不会静默失败。
- MOBI / AZW 只支持非 HUFF 压缩的版本；CHM 只能转成 HTML，不直接出 TXT。
- 「的得地」检查用规则组实现，在搜索等级 1 时与原程序口径接近，但不会完全一致。
- 内置错别字表约 365 条高频词与异形词（原程序是约 18 万条自动生成的定长表，误报很多），
  可以自己往 `typos.txt` 里加。
- 阅读模式是只读的：隐藏行号、去掉当前行高亮、正文收进居中的窄栏，要改就切回整理模式。
- 只支持 Windows：标题栏配色、简繁转换都调用系统 API。
- 打开几十 MB 的单个文件会明显变慢，此时用「按大小分割」先切开更省事。
