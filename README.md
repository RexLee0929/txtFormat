# txtFormat

面向中文长文本（小说、讲稿、转录稿）的整理工具：格式整理、正则查找替换、章节整理、快速审核，
以及 HTML / EPUB / DOCX / MOBI 等格式转 TXT。

这是参照原 **txtFormat 文本校对 V2.10** 重写的版本：界面按 Windows 11 Fluent 重做，代码重构成
「纯逻辑核心 + Qt 界面」两层，原程序说明文档里的处理项逐条对齐。全部功能在本机完成，
不联网、不上传任何内容。

## 30 秒上手

1. 双击安装包，一路点「下一步」。默认「仅为我安装」，装在当前用户目录，不需要管理员权限。
2. 启动后点左侧「文件目录」的文件夹按钮，选一个放 txt 的目录；也可以把文件或整个目录拖进窗口。
3. 双击列表里的文件打开。先到「工具 → 格式整理选项」按需要设行首缩进、标点与数值的全半角。
4. 点命令栏「格式整理」（Ctrl+D）整理全文。不满意就 Ctrl+Z，或用「文件 → 还原为打开时的内容」退回刚打开的样子。
5. Ctrl+S 保存。第一次覆盖原文件时会问一次，同一份文档在本次运行内不再重复询问。

## 它解决什么

| 问题 | 直接用会怎样 | 本程序 |
| --- | --- | --- |
| 网上抓的小说每行都是硬回车，段落全散成一截一截 | 一行行手动接回去 | 格式整理看行尾标点与行宽自动把断行接回去，并跳过「更新时间/本章字数」这类广告行 |
| 标点一会儿全角一会儿半角，英文字母和数字混着 | 逐个改，改到一半就放弃 | 标点 / 英文 / 数值三类分别可设全角、半角或不动；数字里的小数点、URL 里的冒号不动 |
| 每章一个文件，文件名前面顶着站名和序号 | 在资源管理器里手动改名 | 右键批量删掉文件名前 N 个字符、指定字符串、某字符前或后的内容 |
| 正文里夹着广告，随手删容易删掉正文 | 不敢删，留着又难看 | 广告检查只认整行匹配，先把命中项写进 `remove.txt` 让人核对，再一键删除 |
| 一章几万字，打开就卡、滚动就跳 | 硬着头皮往下翻 | 行号、当前行高亮、40 字水线、自动卷屏；阅读模式隐藏行号并锁定编辑 |
| 文件是 ANSI 编码，另存成 UTF-8 后别的软件打不开 | 编码和换行都被改掉 | 读入时记下编码与换行（CRLF/LF/CR），保存按原样写回；要转编码走「重编码」 |
| 章节名缺字、多空格、编号断开 | 逐章核对 | 章节整理列出全部章节、标红编号不连续处，可规范化标题、重排编号、按章节分割 |

## 选项说明

「工具 → 格式整理选项」里的设置决定「格式整理」的结果，也影响 Tab / Shift+Tab 的缩进。
改完即时生效，下次启动沿用；「恢复默认设置」只重置这一组，不动字体和窗口状态。

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 标点符号处理 | 转换为全角 | 可改半角或「不转换（保持原样）」 |
| 英文字符处理 | 转换为半角 | 只影响英文字母，不碰汉字 |
| 数值处理 | 不转换 | 中文正文里数字通常保持半角 |
| 段落间的隔行处理 | 不处理（保持原样） | 可改「隔一行」或「不隔行」 |
| 行首缩进 | 全角空格 | 可改半角空格、制表符或「无缩进」 |
| 缩进个数 | 2 | 0–10 个 |
| 去掉硬回车时的行宽 | 30 字 | 10–255；行尾不是句末标点且超过这个宽度才接下一行 |
| 自动处理硬回车 | 开 | 关掉后保留原文件的所有断行 |
| 文档中包含有广告 | 开 | 关掉后跳过广告识别的整行匹配 |
| 以句号为段落标记重新分段 | 关 | 适合整篇没有分段的稿子 |
| 除去非标题行中的空格 | 开 | 章节标题行里的空格保留 |
| 把 Unicode 码转成汉字 | 开 | `&#29234;`、`&#x7232;` 这类字符引用还原 |
| 还原屏蔽码 | 开 | `少*妇` → `少妇`，词表见 `screened.txt` |
| 还原拼音 | 开 | `sè` → `色`，词表见 `pinyin.txt` |
| 规范不合法的标点组合 | 开 | `，，`、`。。`、`！？`、`：：`、落单的引号 |
| 处理子目录中的文件 | 关 | 打开后选目录会连子目录一起列进文件表 |
| 按文件名中的数字排序 | 开 | 让「第2章」排在「第10章」前面 |

另外几项不在这张表里：字体与字号在「查看 → 字体」（对话框里有「恢复默认值」，一键回到出厂的黑体 14 号），
自动换行、状态栏、自动卷屏、水线在「查看」菜单里勾选，
都会记到同一个配置文件。

## 命名规则

文件表里右键 → 四个批量改名动作，只改文件名主体，扩展名不动，改完仍留在原目录：

| 操作 | 输入 | 输出 |
| --- | --- | --- |
| 删除文件名前面 3 个字符 | `001 第一章 起始.txt` | `第一章 起始.txt` |
| 删除文件名中指定的字符串（`【精校】`） | `【精校】第一章 起始.txt` | `第一章 起始.txt` |
| 删除某字符前的内容（含该字符，填 `（`） | `长篇书名（作者甲）第一章.txt` | `作者甲）第一章.txt` |
| 删除某字符后的内容（保留该字符） | `【完结】第一章 起始.txt` | `【完结】.txt` |

约定几条：

- 改完是空字符串的跳过不改，不会出现无名文件。
- 目标名已被占用时自动加序号，变成 `名字(2).txt`，不覆盖同名文件。
- 目录里已有的其他文件不参与改名，只有文件表里选中的那些会被动。
- 按章节分割出来的文件名会先过一遍非法字符替换（`\ / : * ? " < > |` 换成 `_`，最长 120 字），
  重名同样加序号。

## 格式整理做了什么

点一次「格式整理」，依次做 11 件事（有选区时只处理选区）：

1. 去掉每行行尾的半角空格、全角空格、制表符
2. （可选）以句号、叹号、问号、省略号为段落标记重新分段
3. 按设置转换标点、英文字符、数值的全角半角 —— 数字中的小数点、英文之间的标点、
   `http:` 的冒号、数字字母前后的 `. ? %` 一律不动
4. 删除中文之间的多余空格（章节标题里的空格保留）
5. 自动处理硬回车：行尾不是句末标点且超过行宽时，把下一行接上来
6. `&#29234;` / `&#x7232;` 这类 Unicode 字符引用还原成汉字
7. 删除可识别的广告（整行匹配才删）
8. 应用排版：行首缩进、段落之间隔行或不隔行
9. 还原屏蔽码（`少*妇` → `少妇`）
10. 还原拼音（`sè` → `色`）
11. 规范非法标点组合（`，，`、`。。`、`！？`、`：：`、引号成对）

第 5 步与广告行互斥：`16K小说网 更新时间…本章字数…` 这种行不会被并进正文。
整理完状态栏上方会弹一条提示，写明这次动了多少处；文档已是规范格式时提示「整理完成，文档已经是规范格式」。

## 自动化任务

右栏上半部分可以把常用流程存成任务，省得每次手动按一遍：

- 可用的功能有六种：格式整理、查找替换、简繁转换、去除行尾空格、首尾引号规范化、按 remove.txt 删除广告。
- **每个步骤自带选项**：任务里的格式整理用自己那组设置，与「工具 → 格式整理选项」互不影响；
  同一功能可以加多次（先整理一次 → 查找替换 → 再整理一次）。
- 新建 / 编辑在同一个对话框里完成：加步骤、调顺序、配选项；重名或空任务不给保存。
- 点「运行」在后台按顺序处理当前文档，期间状态栏显示进度，此时正文若被手动改动则丢弃结果；
  完成后弹一条提示，逐行写明每步动了多少处，整体一次 Ctrl+Z 就能全部退回。
- 任务保存在程序目录 `config.json` 的 `automations` 字段，重启后还在，并自动选中上次调用的那个。

## 常见问题

**整理完发现不对，能退回去吗？**
三档退路：Ctrl+Z 撤消；「文件 → 还原为打开时的内容」回到刚打开的样子（保存过也能还原）；
或者直接关掉不保存。

**保存会改掉文件原来的编码和换行吗？**
不会。读入时记下编码（GB18030 / UTF-8 / UTF-8 BOM / UTF-16 LE / BE）和换行（CRLF / LF / CR），
保存按原样写回。要转编码用「工具 → 重编码」，那里才显式指定目标编码和行尾。

**批处理会不会动到我别的文件？**
只处理左侧文件表里的文件：按钮名带 `*` 的（查找、全部替换）勾了「批处理列表内所有文件」才生效，
执行前会弹一次确认，并直接写回磁盘（保留原编码）。右键「从列表移除」只是移出列表，不删磁盘文件；
「删除文件…」才会真删，且有确认框。

**设置存在哪？重装会丢吗？**
存在程序目录的 `config.json`。升级或重装时安装向导检测到这个文件，默认保留、不覆盖；
卸载时「保留个人设置与自定义词表」默认勾选，`config.json` 和 `custreg.txt` 都会留下。

**打开是乱码怎么办？**
先试「工具 → 以 ANSI / UTF-8 / Unicode 方式重新打开」，多半是编码认错了；
文件内容本身就是乱码的，用「查找乱码」定位、「修复选定乱码」按 latin-1 / cp1252 反推。

**内置正则只有 82 条，能自己加吗？**
能。`custreg.txt` 与内置表同一格式（说明、表达式、替换三行一组），放在程序目录或 `%APPDATA%\txtFormat`，
加完点「工具 → 重新载入自定义正则」，列表末尾就是你的条目。

**状态栏的「共 N 字」算的是什么？**
字符数，含标点和空格。「查看 → 统计选定（全部）内容」另给汉字数、行数、标点数、段落数。

**安装时提示需要 .NET Framework 4.8？**
安装向导是 .NET Framework 4.8 程序。Win10 1903 及以后、Win11 都自带；更早的系统需要先装一次，
装完再运行安装包。程序本身不依赖 .NET。

## 已知限制

- 这些历史格式没做：UMD（读与写）、TXT → JAR、TXT → PDF、PDF → TXT、EXE → HTM、HLP → RTF。
  点对应转换时会给一句明确提示，不会静默失败。
- MOBI / AZW 只支持非 HUFF 压缩的版本；CHM 只能转成 HTML，不直接出 TXT。
- 「的得地」检查用规则组实现，在搜索等级 1 时与原程序口径接近，但不会完全一致。
- 内置错别字表约 365 条高频词与异形词（原程序是约 18 万条自动生成的定长表，误报很多），
  可以自己往 `typos.txt` 里加。
- 阅读模式是只读的：隐藏行号、去掉当前行高亮、正文收进居中的窄栏，要改就切回整理模式。
- 只支持 Windows：标题栏配色、简繁转换都调用系统 API。
- 打开几十 MB 的单个文件会明显变慢，此时用「按大小分割」先切开更省事。
