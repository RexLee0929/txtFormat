## **{NAME}** **{VERSION}**

{TAGLINE}

面向中文长文本（小说、讲稿、转录稿）的批量整理工具。全部功能在本地完成，不上传任何内容。

**主要功能**

- 格式整理：行尾清理、标点全半角、硬回车合并、行首缩进、广告清理、屏蔽码与拼音还原
- 正则查找替换：80 余条内置表达式 + 你的 custreg.txt，支持自定义扩充
- 章节整理：章节名规范化、重排编号、按章节或大小分割、多文件合并
- 快速审核：错别字、的得地、引号括号、不规则标点、繁体字、超长段落
- 格式转换：HTML / EPUB / DOCX / PDB / MOBI / JAR / RTF → TXT，CHM → HTML；编码互转，简繁转换

**快捷键**
Ctrl+O 打开　Ctrl+S 保存　Ctrl+Shift+S 另存为　Ctrl+F 查找
F3 查找下一个　Shift+F3 查找上一个　Ctrl+G 转到
Ctrl+D 格式整理　Ctrl+Shift+F 快速审核　Ctrl+Shift+A 广告检查
Tab / Shift+Tab 缩进 / 反缩进　Ctrl+= / Ctrl+- 缩放字号
